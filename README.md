# LARNG
Loomis's Aura RNG

A cosmic aura-collecting RNG game. Built with React, TypeScript, and Vite.

## Development

- `npm install`
- `npm run dev`
- `npm run build`
- `npm test`

## Current prototype

The first playable foundation includes rolling, rarity tiers, local save data, inventory, collection index, luck/speed upgrades, and duplicate dismantling.
